# LLM Wiki Schema

## Правила
- Все файлы — в markdown, UTF-8
- Ссылки только в формате [[WikiLink]]
- Новые страницы создавай только через шаблоны из _templates/

## Воркфлоу ингейста
1. Прочитай файл из raw/
2. Выдели ключевые сущности и концепции
3. Создай/обнови страницы в knowledge/
4. Обнови index.md и логи

## Запреты
- Не правь файлы в raw/
- Не создавай файлы вне knowledge/ без согласования
- Не удаляй страницы, только предлагай архивацию
